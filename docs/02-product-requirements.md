## 1. 产品定位

**一句话**：一个具有 AI 工作台视觉语言的现代内容阅读、检索与整理空间。

**仍然是博客**——不做成聊天软件。借鉴 AI 工作台的**视觉与交互特征**（大面积留白、中性灰、大圆角主面板、工作台式侧栏、集中式搜索入口），但功能内核是内容阅读。

**设计关键词**：Minimal SaaS · AI Workspace · Content Workspace · Soft Minimalism · Neutral Gray · Large Whitespace · Calm Interface · Editorial Reading · Desktop-first · Accessible Responsive UI。

**明确不做**：高饱和渐变 / 霓虹 / 玻璃拟态 / 新拟态 / 厚重阴影 / 复杂纹理 / 装饰性动画 / 大封面卡片瀑布流 / 营销式 Hero。

---

## 2. 目标用户

| 用户     | 场景                               |
| -------- | ---------------------------------- |
| 作者本人 | 维护文章、回顾归档、快速定位旧文   |
| 读者     | 阅读长文、按主题探索、检索特定内容 |

---

## 3. 核心任务（用户视角）

1. **读**：打开文章，舒适阅读长文（中文正文、代码、表格）。
2. **找**：用搜索或分类/标签/专题快速定位内容。
3. **逛**：从首页工作台看到最近/精选/主题入口。
4. **回**：找到「最近读过」的内容（本地记忆，非账号）。

## 6. 各页面需求

### 首页（HomeView）

- 欢迎区（品牌 + 一句介绍 + 文章/项目计数）。
- 热门主题（标签云或主题胶囊）。
- **搜索入口**（首页视觉核心，站内搜索，非聊天框）。
- 精选文章（无大图的轻卡片列表）。
- 最近更新。
- 空/加载/错误状态。

### 文章列表（ArticleListView）

- 分页列表；每项：标题 / 摘要 / 分类或专题 / 标签 / 日期 / 阅读时间 / 轻箭头。
- 无大封面图。
- 排序与筛选（按分类/标签）。

### 文章详情（ArticleDetailView）

- 阅读宽度受限（约 680–760px）；行高 1.7–1.9；正文 ≥16px。
- 目录（TOC）高亮；代码块可复制；表格移动端不溢出；长链接换行；图片不溢出。
- 上下篇、相关文章、系列路径。

### 搜索（SearchView）

- 按标题/描述/正文/标签/分类。
- 范围筛选、清除、无结果状态、词高亮、URL 可分享、防抖。
- 键盘：`/` 或 `Ctrl/Cmd+K` 聚焦；↑↓ 选择；Enter 打开。

> **实施现状（2026-10-07 迭代 08 复核；2026-10-10 R14 处置更新，见 D-045）：**
>
> | 要求                       | 现状            | 说明                                                                                                                          |
> | -------------------------- | --------------- | ----------------------------------------------------------------------------------------------------------------------------- |
> | 标题/描述/标签/分类        | ✅ 已实现       | `src/lib/search/engine.ts` 的 Fuse keys                                                                                       |
> | **正文**                   | ❌ **明确不做** | 20 篇规模下正文索引会把 ~100KB 串数据塞进客户端，与「轻量客户端」取向相反（D-045 定案）                                       |

> | **词高亮**                 | ✅ 已实现       | `includeMatches` + `highlightSegments` 纯函数，title/description 命中段 `<mark>`（D-045）                                     |
> | URL 可分享                 | ✅ 已实现       | 查询写入当前路径 `?q=`                                                                                                        |

>
> 原先「三项未实现待定」的状态已处置：词高亮补齐（D-045）；正文索引与范围筛选经规模评估后**明确不做**——这是需求定案，不是欠账。

### 分类 / 标签 / 专题（CategoryView / TagView / SeriesView）

- 聚合列表 + 详情；复用 ArchiveCard。

### 移动端

- 隐藏固定侧栏 → Sheet；点击区 ≥40px；无横向滚动；正文边距充足。

---

## 7. 状态要求（所有核心页面）

正常 / 空 / 加载（Skeleton）/ 错误 / 无结果 / 数据缺失；超长标题与标签；无封面、无描述、无分类；窄屏；慢网；JS 不可用时的基础可读性。

---

## 8. 成功指标

- 全站无死链（导航/页脚/错误页）。
- `typecheck` / `lint` / `test` / `build` 全绿。
- 首页到任意文章 ≤ 2 次点击。
- 搜索从输入到出结果 < 200ms（20 篇规模，客户端）。
- Lighthouse mobile performance ≥ 90（沿用现有预算）。
- 键盘可完成主导航 + 搜索。
