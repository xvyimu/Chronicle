## 1. 全站 Sitemap

```
/                       首页（工作台）
├── /blog               文章列表
│   └── /blog/[slug]    文章详情
├── /categories         分类索引
│   └── /categories/[category]
├── /tags               标签索引
│   └── /tags/[tag]
├── /series             专题索引
│   └── /series/[series]
├── /archive            归档（新增，按时间）
├── /projects           作品集
│   └── /projects/[id]
├── /about              关于
└── /api/csp-report     CSP 上报（非页面）
```

**已移除**（上一轮）：`/garden` · `/links` · `/api/search` · `/api/preview/[slug]`。

---

## 2. 页面层级与主导航

**TopBar**（全站）：品牌 · 全局搜索入口 · 主题切换 · RSS · 外部链接（GitHub）。
**Sidebar**（桌面）：首页 · 文章 · 专题 · 分类 · 标签 · 归档 · 关于。
**次级导航**：列表页顶部的分类/专题跳转；文章页的面包屑。

导航配置 SSOT：`src/lib/navigation.ts`（**当前含已删的 `/garden` `/links` 死链，待修**，见审计 E1）。

---

## 3. 面包屑策略

- 文章页：`首页 / 博客 / <分类> / <标题>`（分类缺省时 `首页 / 博客 / <标题>`）。
- 分类/标签/专题详情：`首页 / <分类|标签|专题> / <值>`。
- 首页与一级索引页不显示面包屑。

---

## 4. 移动端导航

固定侧栏隐藏 → 顶栏汉堡 → Sheet 抽屉（复用 `components/ui/sheet.tsx`）。底部不另设 TabBar（内容站，非 App）。

---

## 5. URL 设计

- 保持现有：`/blog/<slug>`（slug = 文件名去 `YYYY-MM-` 前缀）、`/categories/<值>`、`/tags/<值>`、`/series/<值>`。
- **不修改任何已发布 slug**（硬约束）。
- 中文路径参数使用 `encodeURIComponent`。
- 新增 `/archive`，不改既有。

## 6. 旧 URL 兼容

| 旧 URL       | 处置                                         |
| ------------ | -------------------------------------------- |
| `/garden`    | 已删；导航死链待清（不重定向，直接移除入口） |
| `/links`     | 已删；同上                                   |

## 7. 页面跳转关系

```
首页 ──┬─→ 文章列表 ─→ 文章详情 ─┬─→ 上一篇/下一篇
       ├─→ 专题 ─→ 专题详情      ├─→ 相关文章
       ├─→ 分类 ─→ 分类详情      └─→ 系列路径
       ├─→ 标签 ─→ 标签详情
       ├─→ 归档
       └─→ 作品集 ─→ 作品详情
```

## 8. 搜索结果信息结构

每项：标题 · 高亮匹配片段 · 分类/标签 · 日期 · 链接。结果按相关度排序。

## 9. 文章详情信息结构

标题 → 元信息（日期/更新时间/阅读时间/分类/标签）→ 正文（含 TOC 侧栏）→ 系列路径 → 相关文章 → 上下篇。
